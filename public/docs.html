Train Information

GET /train/:name

Returns stop data for all stops that match the given name.

{
  "status": "200",
  "train": "State",
  "stops": [ { "id": "70041", "name": "State", "line": "Blue Line" } ],
  "count": 1
}

GET /train/id/:id

Returns stop details for a specific stop ID.

{
  "status": "200",
  "stop": { "id": "70041", "name": "State", "line": "Blue Line" }
}

GET /train/closest/:lat/:long

Finds the stop closest to the given latitude and longitude using the Haversine formula. Returns stop details and distance in kilometers.

{
  "status": "200",
  "closestStop": { "id": "70041", "name": "State", "line": "Blue Line" },
  "distanceKm": 0.412
}

GET /stop/next/:stop

Returns the current stop and the next stop in sequence, looked up by stop name.

{
  "status": "200",
  "currstop": { "name": "Alewife", "train_line": "Red Line" },
  "nextstop": { "name": "Davis", "train_line": "Red Line" }
}

Lines

GET /line/:name

Returns all stops along the given line name, with a total count.

{
  "status": "200",
  "line": "Blue Line",
  "stops": [ { "id": "70041", "name": "State" }, { "id": "70042", "name": "Airport" } ],
  "count": 2
}

GET /route/:start/:end

Returns the optimal route between two stops by name using Dijkstra's algorithm. Transfer penalties are applied when switching lines. URL-encode stop names that contain spaces.

{
  "status": "200",
  "start": "Alewife",
  "end": "Park Street",
  "cost": 7,
  "stops": 8,
  "path": ["Alewife", "Davis", "Porter", "Harvard", "Central", "Kendall/MIT", "Charles/MGH", "Park Street"]
}

Live Data

GET /times/both/:stopId/:nextnum

Returns the next nextnum inbound and outbound trains for the stop with ID stopId.

{
  "status": "200",
  "stopId": "70041",
  "inbound": [ "Train A at 12:40", "Train B at 12:55" ],
  "outbound": [ "Train C at 12:42", "Train D at 12:58" ]
}

GET /times/in/:stopId/:nextnum

Returns the next nextnum inbound trains for the stop with ID stopId.

{
  "status": "200",
  "stopId": "70041",
  "direction": "inbound",
  "data": [ "Train A at 12:40", "Train B at 12:55" ]
}

GET /times/out/:stopId/:nextnum

Returns the next nextnum outbound trains for the stop with ID stopId.

{
  "status": "200",
  "stopId": "70041",
  "direction": "outbound",
  "data": [ "Train C at 12:42", "Train D at 12:58" ]
}
