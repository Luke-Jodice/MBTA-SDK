Train Information

GET /train/:name

Returns stop data for all stops that match the given name.

{
  "status": "200",
  "train": "State",
  "stops": [ { "name": "State", "train_line": "Blue Line", "line_short": "place-state" } ]
}

GET /train/id/:id

Returns stop details for a specific place ID (e.g. place-sstat).

{
  "status": "200",
  "stop": { "name": "South Station", "train_line": "Red Line", "line_short": "place-sstat" }
}

GET /train/closest/:lat/:long

Finds the stop closest to the given latitude and longitude using the Haversine formula. Returns stop details and distance in kilometers.

{
  "status": "200",
  "closestStop": { "name": "State", "train_line": "Blue Line" },
  "distanceKm": 0.412
}

GET /stop/next/:stop

Returns the current stop and the next stop in sequence, looked up by stop name.

{
  "status": "200",
  "currstop": { "name": "Alewife", "train_line": "Red Line" },
  "nextstop": { "name": "Davis", "train_line": "Red Line" }
}

Stops

GET /stops/search?q=

Fuzzy search stops by partial name. Returns all stops whose name contains the query string (case-insensitive).

{
  "status": "200",
  "query": "park",
  "count": 2,
  "results": [
    { "name": "Park Street", "train_line": "Green/Red Line" },
    { "name": "Alewife", "train_line": "Red Line" }
  ]
}

GET /stops/accessible

Returns all stops with full wheelchair accessibility (wheelchair_boarding = 1).

{
  "status": "200",
  "count": 52,
  "stops": [ { "name": "Alewife", "train_line": "Red Line", "wheelchair_boarding": 1 } ]
}

Lines

GET /line/:name

Returns all stops along the given line name, with a total count.

{
  "status": "200",
  "line": "Blue Line",
  "stops": [ { "name": "State" }, { "name": "Airport" } ],
  "count": 12
}

GET /route/:start/:end

Returns the optimal route between two stops by name using Dijkstra's algorithm. Transfer penalties are applied when switching lines. URL-encode stop names that contain spaces.

{
  "status": "200",
  "start": "Alewife",
  "end": "Park Street",
  "cost": 7,
  "stops": 8,
  "path": ["Alewife", "Davis", "Porter", "Harvard", "Central", "Kendall/MIT", "Charles/MGH", "Park Street"]
}

Live Data

GET /times/both/:stopId/:nextnum

Returns the next nextnum (1–5) inbound and outbound trains for the stop with place ID stopId.

{
  "status": "200",
  "stopId": "place-sstat",
  "inbound": [ { "time": "12:40 PM", "endStop": "Alewife" } ],
  "outbound": [ { "time": "12:42 PM", "endStop": "Braintree" } ]
}

GET /times/in/:stopId/:nextnum

Returns the next nextnum inbound trains for the stop.

{
  "status": "200",
  "stopId": "place-sstat",
  "direction": "inbound",
  "inbound": [ { "time": "12:40 PM", "endStop": "Alewife" } ]
}

GET /times/out/:stopId/:nextnum

Returns the next nextnum outbound trains for the stop.

{
  "status": "200",
  "stopId": "place-sstat",
  "direction": "outbound",
  "outbound": [ { "time": "12:42 PM", "endStop": "Braintree" } ]
}

Streaming (SSE)

GET /times/stream

Streams real-time train predictions as Server-Sent Events (SSE). Pushes a new times event on each interval with fresh inbound and outbound data.

Query parameters:

  • stopId (required) — place ID of the stop
  • interval (optional, default 30) — polling interval in seconds (5–300)
  • nextnum (optional, default 3) — number of upcoming trains to return (1–5)
curl -N "http://localhost:3000/times/stream?stopId=place-sstat&interval=20&nextnum=3"

# Each event looks like:
event: times
data: { "at": "2026-06-01T18:00:00Z", "stopId": "place-sstat",
        "inbound": [...], "outbound": [...] }

GET /times/reset

Returns a fresh prediction snapshot on demand. Useful for forcing a data refresh outside the stream interval.

Query parameters:

  • stopId (optional) — if provided, returns fresh inbound/outbound data
  • nextnum (optional, default 3)
GET /times/reset?stopId=place-sstat&nextnum=3

{
  "status": "200",
  "message": "Train timings reset with fresh data.",
  "stopId": "place-sstat",
  "inbound": [ { "time": "12:40 PM", "endStop": "Alewife" } ],
  "outbound": [ { "time": "12:42 PM", "endStop": "Braintree" } ]
}
